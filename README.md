# Moate32 儿童版

玛特桌面终端（Mosmori）儿童版固件与配套 SD 卡资源发布页。固件面向 320×240、GT911 板载屏硬件。

作者：SamuelKK& 请叫我奉孝大人（dy）

## 本次版本

- 固件：1.0.12K（development 构建）
- 资源包：`resources/moate32-kids-sd-resources-1.0.12K.zip`
- 固件文件：`firmware/moate32-kids-1.0.12K-development.bin`
- SHA-256 校验值见 `SHA256SUMS.txt`。

## 服务器与本机功能

**没有 Bridge 服务器时**，板子仍可运行本机功能。手机与板子接入同一 Wi-Fi 后，可打开板载网页，直接读取或修改板上作业、闪卡和学习设置；数据写入板载 LittleFS。英语、诗词等资料和朗读资源从 SD 卡读取。本地网页通信不需要互联网或云服务器。天气由板子直接请求 Open-Meteo；没有互联网时天气无法更新。

**Bridge 服务器在线时**，固件可使用 WebSocket 连接它，同步学习记录与配置，并提供 Bridge 后端支持的远端功能。它面向以后多端接入或跨网同步。Bridge 不在线不会阻止上述本机功能；跨设备、跨网络同步则需要服务器在线。

当前手机网页要求手机和板子在同一 Wi-Fi 网络。若要在没有路由器的环境下操作，需另行配置板载热点模式。

## SD 卡安装

将资源包解压后，把其中的 `s032` 目录直接复制到 SD 卡根目录。请使用同一发布版本配套的固件和资源包，并在刷写/复制前核对 SHA-256。
