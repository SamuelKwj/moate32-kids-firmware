# Moate32 儿童版

> 一个运行在 ESP32 小屏终端上的本地儿童学习与陪伴固件。  
> 不依赖云端才能工作，也不要求一直连接电脑。  
> 插上电，它首先应该是一台属于孩子自己的小终端。

**Moate32 儿童版**是基于 ESP32-2432S032 / 320×240 触摸屏硬件制作的一套儿童学习终端固件。

它把一些适合放在桌面终端上的轻量功能——作业、闪卡、英语、诗词、朗读、天气、学习设置等——放进一块小小的 ESP32 屏幕里。

项目同时保留了联网和 Bridge 扩展能力，但设计原则是：

> **服务器是增强，不是前提。**

即使没有运行 Bridge，设备仍然可以独立完成大部分本地功能。

# ✨ 它能做什么

Moate32 儿童版并不是把一个网页简单塞进 ESP32。

它包含三个相对独立的部分：

```text
┌─────────────────────────────┐
│        Moate32 终端          │
│                             │
│  本地 UI / 学习 / 设置       │
│  LittleFS 本地数据           │
│  SD 卡学习与朗读资源         │
└─────────────┬───────────────┘
              │
       Wi-Fi / 局域网
              │
     ┌────────┴─────────┐
     │                  │
 手机本地管理页      Bridge（可选）
     │                  │
 修改学习内容        多设备同步
 作业 / 闪卡         跨网络能力
 学习设置            后端扩展
```

也就是说：

**设备本身可以工作。**

手机网页是一种管理方式。

Bridge 则是一层可选的增强能力。

---

# 🧒 本地学习功能

即使电脑没有运行 Bridge，设备仍然可以使用本地学习相关能力。

当前儿童版的数据主要分为两类。

### 板载数据

作业、闪卡、学习设置等轻量数据可以保存在 ESP32 板载 **LittleFS** 中。

因此设备重启以后，相关数据仍然可以保留。

### SD 卡资源

体积较大的资料和媒体资源放在 SD 卡中，例如：

- 英语学习资料
- 诗词内容
- 朗读资源
- 配套学习文件
- 其他静态资源

这样可以避免占用 ESP32 有限的 Flash 空间，同时也方便以后独立替换或增加内容。

---

# 📱 手机也可以管理

Moate32 儿童版内置了本地网页能力。

只要：

```text
手机
  │
  ├── 接入同一个 Wi-Fi
  │
Moate32
```

手机和设备位于同一局域网，就可以通过浏览器访问板载网页。

不需要把学习数据先发送到云服务器。

手机端可以用于读取或修改设备中的部分学习数据，例如：

- 作业
- 闪卡
- 学习设置
- 本地配置

修改后的数据可以直接写入设备的 LittleFS。

---

## 为什么这么设计？

因为儿童终端最基础的功能，不应该因为：

- 云服务器停止
- Bridge 没启动
- 电脑关机
- 第三方服务异常

就完全无法使用。

所以这套固件尽可能把**基础能力留在设备本身**。

---

# ☁️ Bridge 是什么？

Bridge 是 Moate32 体系中的可选服务器层。

当 Bridge 在线时，设备可以通过 WebSocket 与服务器建立连接，获得更多能力，例如：

- 学习记录同步
- 配置同步
- 多设备数据交换
- 跨网络功能
- Bridge 后端提供的其他扩展能力

但需要再次强调：

> **没有 Bridge，不等于设备不能使用。**

Bridge 离线时，本地学习、SD 卡资料以及局域网手机管理仍然可以继续运行。

---

# 🌦 天气功能

天气数据由设备直接请求 **Open-Meteo**。

因此天气功能：

```text
需要 Wi-Fi
   +
需要互联网
```

但：

```text
不需要 Bridge
```

如果网络无法访问互联网，天气不会更新，但不会影响设备上的本地学习功能。

---

# 🌐 三种运行状态

为了更容易理解，可以把设备的网络状态分成三种。

| 状态 | 本地学习 | SD 资源 | 手机管理 | 天气 | Bridge 同步 |
| --- | --- | --- | --- | --- | --- |
| 无互联网 | ✅ | ✅ | 同局域网可用 | ❌ | ❌ |
| 有互联网，无 Bridge | ✅ | ✅ | ✅ | ✅ | ❌ |
| 有互联网，有 Bridge | ✅ | ✅ | ✅ | ✅ | ✅ |

# 📡 当前局域网限制

目前手机管理页面要求：

> **手机和 Moate32 接入同一个 Wi-Fi。**

例如：

```text
家中路由器
 ├── 手机
 └── Moate32
```

两台设备在同一局域网中即可。

目前这个版本并没有默认把“设备自身开启热点”作为主要使用方式。

如果希望：

```text
没有路由器
     ↓
手机直接连接 Moate32
```

则需要另外配置设备 AP / 热点模式。

# 🖥️ 硬件目标

当前固件构建目标为 ESP32-2432S032 一类 320×240 触摸屏开发板。

主要硬件环境：

| 硬件 | 配置 |
| --- | --- |
| MCU | ESP32 |
| 显示分辨率 | 320 × 240 |
| LCD | ST7789 系列 |
| 触摸控制器 | GT911 |
| 存储 | ESP32 Flash + SD Card |
| 网络 | 2.4 GHz Wi-Fi |

当前工程所使用的 GT911 配置来源于 Moate32 硬件环境。

不同批次的 ESP32-2432S032 板子可能存在：

- 屏幕驱动不同
- 触摸芯片不同
- 引脚定义不同
- 背光控制不同
- SD 接线不同

所以：

> **外观看起来一样，不代表硬件一定完全兼容。**

刷写前请确认自己的板子型号。

# 💾 SD 卡安装

下载：

```text
moate32-kids-sd-resources-1.0.12K.zip
```

解压后，你会看到：

```text
s032
```

目录。

将整个 `s032` 文件夹复制到 SD 卡根目录。

最终结构应类似：

```text
SD CARD
│
└── s032
    ├── ...
    ├── ...
    └── ...
```

注意不是：

```text
SD CARD
└── moate32-kids-sd-resources-1.0.12K
    └── s032
```

也不是：

```text
SD CARD
└── s032
    └── s032
```

设备需要直接在 SD 卡根目录找到：

```text
/s032/
```

# 🔥 固件刷写说明

固件文件：

```text
moate32-kids-1.0.12K-development.bin
```

当前构建使用 ESP32 OTA 分区结构，其中应用分区起始地址为：

```text
0x10000
```

如果你的板子**已经具有兼容的 Bootloader 和 Partition Table**，可以将应用固件写入对应的 App 分区。

例如使用支持 ESP32 的刷机工具时，应用固件地址通常为：

```text
0x10000
```

## ⚠️ 第一次刷空白 ESP32 请注意

当前公开 Release 提供的是：

```text
应用 firmware.bin
```

并不是完整的整片 Flash 镜像。

也就是说，如果你面对的是一块完全空白的 ESP32：

```text
Bootloader
Partition Table
OTA Data
Application
```

这些内容并不全部包含在单独的 `firmware.bin` 中。

因此当前版本更适合：

- 已经运行过兼容 Moate32 固件的设备
- 已经具有兼容 Bootloader / Partition Table 的开发板
- 熟悉 ESP32 刷写结构的开发者

不要在不了解 Flash 布局的情况下随意填写刷写地址。

# 📴 如果服务器挂了会怎样？

这是这个版本比较重要的一点。

假设：

```text
Bridge 服务器关闭
```

仍然可以使用：

- 板载学习功能
- 本地作业
- 本地闪卡
- 学习设置
- SD 卡学习资源
- SD 卡朗读资源
- 手机同局域网管理
- LittleFS 本地保存

不能使用或会受到影响的是：

- Bridge 数据同步
- 跨设备同步
- 跨网络功能
- Bridge 后端提供的扩展能力

天气与 Bridge 无关。

只要设备本身可以访问互联网，Open-Meteo 天气仍然可以工作。

---

# 📂 数据保存在哪里？

简单理解：

```text
小数据
↓
ESP32 LittleFS

大资源
↓
SD Card

服务器同步数据
↓
Bridge
```

这种设计的目的，是让设备即使脱离电脑和服务器以后，仍然保持基本可用状态。

# ⚠️ 当前版本限制

这个版本仍然属于早期公开测试版本。

目前需要注意：

1. **这是 development 构建**

   不是最终稳定版。

2. **本次 Release 没有重新完成完整实机刷写验收**

   因此不同硬件批次上仍有可能出现兼容问题。

3. **手机管理目前主要面向同局域网**

   默认不是公网管理系统。

4. **天气依赖互联网**

   没有网络时不会更新天气。

5. **跨网络同步依赖 Bridge**

   Bridge 不影响本地学习，但影响服务器能力。

6. **OTA 当前关闭**

   固件更新需要手动完成。

7. **不同 ESP32-2432S032 板子可能并不完全相同**

   刷写前请确认屏幕、触摸和硬件版本。

# ❤️ 为什么做儿童版？

ESP32 的算力并不强。

320×240 的屏幕也不大。

它当然无法取代电脑、平板，更不应该试图取代父母和老师。

但我一直觉得：

**科技不一定非得以“更大、更快、更强”的方式存在。**

有时候，一块放在孩子书桌上的小屏幕，能够提醒今天还有什么作业，翻一张英语闪卡，读一首诗，播一段朗读，看看今天的天气——就已经足够有意义。

它可以很小。

可以不依赖昂贵硬件。

可以在断开服务器之后依然继续工作。

也可以让一个普通人，通过代码、AI 和一点点耐心，把自己脑子里的想法真正做成一个摸得到的东西。

Moate32 儿童版还远远谈不上成熟。

所以这次把它放出来。

有人愿意用，就用。

有人愿意改，就折腾。

有人愿意继续把它变得更好，那就更好了。
